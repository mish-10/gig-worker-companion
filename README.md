# Gig Worker Companion (गीग वर्कर साथी)

A full-stack, mobile-responsive web application designed for Indian gig workers, delivery partners (Swiggy, Zomato, Zepto, Blinkit, Porter), and cab drivers (Uber, Ola, Rapido).

Built with **React**, **TypeScript**, **Tailwind CSS**, and **Node.js/Express** with direct **Google Gemini 3.8 Flash** (`@google/genai`) integration.

---

## 🌟 Key Features

1. **AI Companion (Gemini 3.8 Flash)**
   - Ask real-time questions in English or Hindi (Devanagari).
   - Practical advice on platform rules, arbitrary deactivations, e-Shram card benefits, road accident insurance claims, 1% TDS recovery, and fuel efficiency.
   - Maintains conversation history and context across follow-up queries.
   - Real-time loading indicators and error handling with retry capability.

2. **Earnings Tracker & Real Take-Home Calculator**
   - Record gross fares, target incentives, customer tips, fuel costs, repairs, food/data, and platform deductions.
   - Computes true disposable net profit: `Net = (Gross + Incentives + Tips) - (Fuel + Maintenance + Data + Deductions)`.
   - Visual performance charts comparing net earnings against expenses.
   - Clearly labeled demo data with one-click custom shift additions and CSV export.

3. **Government Schemes & Social Security**
   - Verified official schemes: e-Shram (NDUW), PMSBY (₹2L Accidental cover for ₹20/yr), PMJJBY (₹2L Life cover for ₹436/yr), Ayushman Bharat PM-JAY (₹5L cashless hospitalization), PM SVANidhi (₹10,000–₹50,000 subsidized micro-credit), and State Gig Worker Welfare Boards (Rajasthan & Karnataka model).
   - Direct links to official government domains (`eshram.gov.in`, `pmjay.gov.in`, `financialservices.gov.in`, `pmsvanidhi.mohua.gov.in`).

4. **Safety & Emergency Centre**
   - Immediate 5-step post-accident standard operating protocol.
   - One-tap SOS calling for **112** (National Emergency), **108** (Ambulance), **1073** (Road Accident), **1033** (NHAI Highway Breakdown), and **1915** (National Consumer Helpline).
   - Central Motor Vehicles Rules (CMVR) Rule 139 protection: DigiLocker/mParivahan legal validity and anti-key-snatching rules.

5. **Document Assistant & 1% TDS Refund Calculator**
   - Simple guides for Commercial Driving Licence (DL), Vehicle Registration (RC), Commercial Vehicle Insurance with ₹15L CPA cover, and Police Clearance Certificates (PCC).
   - Interactive 1% TDS calculator to show how much tax deducted by platforms under Section 194-O can be claimed back from the Income Tax department.

6. **Formal Dispute Complaint Generator**
   - AI-powered generator that drafts formal, legally structured complaint notices for unpaid payouts, unfair penalty deductions, and sudden account suspensions.
   - Cites Section 11 of Information Technology (Intermediary Guidelines) Rules, Consumer Protection Act 2019, and Natural Justice principles.
   - 3-tier escalation guidance (Platform Grievance Officer → National Consumer Helpline 1915 → State Labour Commissioner).

## 🛠️ Tech Stack & Architecture

- **Frontend**: React 19, TypeScript, Tailwind CSS v4, Lucide Icons, Motion
- **Backend**: Node.js, Express, tsx
- **AI Integration**: `@google/genai` TypeScript SDK using `gemini-3.8-flash`
- **Security**: Server-side runtime proxy (`/api/chat`, `/api/generate-complaint`). The `GEMINI_API_KEY` is strictly held on the server and is never exposed to browser bundles.

## 🚀 Setup & Local Execution

### Prerequisites
- Node.js (v18+)
- npm or yarn
- Gemini API Key

### Installation

1. Clone or download the repository.
2. Install dependencies:
   ```bash
   npm install
   ```

3. Set up environment variables:
   Create a `.env` file based on `.env.example`:
   ```bash
   GEMINI_API_KEY="your-gemini-api-key-here"
   PORT=3000
   ```

4. Start development server:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

5. Build for production:
   ```bash
   npm run build
   npm start
   ```

## 🌐 Deploying to Render (Web Service)

To deploy on [Render](https://render.com):

1. **Create a New Web Service** connected to your repository.
2. Configure Settings:
   - **Environment**: `Node`
   - **Build Command**: `npm install && npm run build`
   - **Start Command**: `npm start`
3. Add Environment Variables in the Render Dashboard:
   - `GEMINI_API_KEY`: Your Gemini API key from [Google AI Studio](https://aistudio.google.com/app/apikey).
   - `NODE_ENV`: `production`
4. Deploy! Render automatically provides `process.env.PORT` which the Express server binds to on `0.0.0.0`.

## 🔍 How to Verify Real AI Integration in Code

To verify that the AI answers are dynamically generated by Gemini rather than hardcoded:

1. **Inspect Server-Side Code (`server.ts`)**:
   - Lines 36–125: Endpoint `POST /api/chat` passes the user's conversational message array directly to:
     ```ts
     const response = await ai.models.generateContent({
       model: 'gemini-3.8-flash',
       contents: formattedContents,
       config: { systemInstruction: ... }
     });
     ```
   - Lines 128–205: Endpoint `POST /api/generate-complaint` builds a dynamic prompt with the worker's dispute parameters and queries Gemini.
2. **Inspect Frontend Code (`src/components/AICompanionView.tsx` & `ComplaintGeneratorView.tsx`)**:
   - The frontend calls `fetch('/api/chat', ...)` and `fetch('/api/generate-complaint', ...)`.
   - The UI displays the response directly from `data.content` and `data.complaint`.
3. **Live Testing in the App**:
   - Open the **AI Companion** tab.
   - Type any unique or complex scenario (e.g., *"If a customer in Indiranagar falsely reported order spill but I took a photo, how do I appeal?"*).
   - Gemini dynamically analyzes the specifics, cites practical Indian platform appeal steps, and structures the response in real time.
